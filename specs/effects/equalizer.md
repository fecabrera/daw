# Three-band EQ

Implementation requirements and design records. For user instructions, see the [user guide](../../docs/effects/equalizer.md).

The Effects catalog in Timeline and Instrument lists **3-band EQ**. Catalog items use the shared control panel's 8-point padding on every side and the theme's 11-point small text style. Unselected names use the same dim text as inactive view controls. Hover/focus uses default text. A single click selects an item with default text and the active view control's accent-tinted fill; selection is UI-only and retained across view/track switches. Select an audio or MIDI track, or Master, then double-click the name to append an instance to its serial effects lane. Single clicks do not add effects or mark the project as modified. Right-click an installed unit header to remove it. Multiple instances keep independent settings and IDs.

Single-click an installed effect unit to select it. Shift-click toggles its selection. A primary click in the empty effects lane clears all unit selections. Selected units reuse the selected Tracks border. Selection is UI-only, independent of track/clip and catalog selection, and does not mark the project modified. It survives view changes and reordering; removed IDs are pruned and project replacement clears it. Drag an effect header to move the selected units within its selected chain. Dragging an already selected instance retains the selection; dragging an unselected instance selects it. Show an insertion line and scroll at the lane edges. Commit the order only on release inside the lane; Escape, focus loss, a blocked editing environment, or an outside drop cancels. Preserve stable IDs, settings, enable/collapse states, and compatible DSP history. Same-position drops leave the project clean. Power and knob gestures retain their behavior, and header double-click still collapses the unit. Move selected units as a group in their existing chain order, even when selection clicks occurred in another order or units were separated. Leave unselected units in their existing order.

The unit reuses the shared unit header, power control, horizontal collapse, knob widget, strip layout, and footer pairs. Three 90-point strips end with Power/Low, Power/Mid, and Power/High. Low and High contain Gain, Frequency, and Q rows. Mid contains only Gain; its footer stays aligned with the outer strips. Footer pairs use the oscillator's 18-point button, 8-point gap, 11-point label, and centered alignment. The Effects catalog header's Up/Down control switches the selected track's lane between the shared 244-point expanded height and 68-point compact height. Compact mode retains headers and footer pairs. Unit headers still collapse horizontally. Effects units omit their bottom border and share the status bar's single thin separator.

Each expanded strip has a four-point horizontal output-level monitor below the header, using the shared Limiter rail layout and painting. The rails show Low, Mid, and High stereo peaks on the shared −60 to 0 dBFS scale. Enabled bands use accent fill; the error color shows peaks above 0 dBFS. A disabled band uses the theme palette's secondary color for its fill, including peaks above 0 dBFS. The shared `band_level_rail` receives the band's enabled state; this changes only the fill color. Whole-unit bypass does not change this band-state rule. Tooltips and accessibility readings retain levels above the display range. These are read-only monitors and do not change saved settings. Compact lanes and horizontally collapsed units hide them. Paused, stopped, or absent output shows empty rails.

The portable EQ analyzes its final stereo output through separate two-pole low-pass and high-pass filters with Q = 1/√2; Mid cascades a high-pass at the lower boundary and a low-pass at the upper boundary. Analysis follows the smoothed outer frequency controls, using their ordered lower/upper values when crossed; equal boundaries have no middle range. These finite-slope analysis ranges overlap near their boundaries. Monitoring combines the higher absolute channel level with instant peak attack and a 300 ms exponential release. Gain, cuts, and bypass are reflected in the measured output; bypass shows the dry signal. Stop and seek reset analysis history and levels; Pause retains history. Prepared atomic handles share the existing three-band monitoring path with OTT and follow stable effect IDs on tracks and Master. Analysis runs only when a handle is attached, does not enter the audio path, and allocates or locks nothing while processing, resetting, or retargeting. Monitoring adds no saved fields or audio latency.

| Parameter | Range | Default |
| --- | --- | --- |
| Gain | −24 to +24 dB | 0 dB for each band |
| Frequency | 20 Hz to 20 kHz, logarithmic control | Low 250 Hz; High 2.5 kHz; Mid uses these boundaries |
| Q | 0.1 to 10, logarithmic control | 1/√2 for Low/High; Mid uses these edge controls |

Low and High use shelves. Mid is a middle shelf made from opposing shelves: its Gain sets the plateau between Low and High frequency boundaries. It uses those bands' Q values for its edges and has no independent Frequency or Q controls. A footer control turns its band off without changing saved gain or other parameters. Low off applies a high-pass cut; High off applies a low-pass cut. Mid off rejects the range between the Low and High frequency values. Each outer Q controls its corresponding cut edge's steepness: higher Q uses more low/high-pass stages (one to eight per branch, with interpolation between adjacent stage counts). Crossed shelf frequencies use their lower/upper values as boundaries, retaining each boundary's Q; equal boundaries leave no middle range. Middle shelf gain and cut blend to unity/dry as the boundaries approach one another. Filter transitions occur around the boundaries; this is a finite-order cut, not a brick-wall filter. With all three bands off, the enabled unit produces exact silence after the 5 ms transition, including residual audio in the filters' overlapping transition ranges. Filters keep advancing so re-enabling a band retains their history. The whole unit's header power bypasses all three bands and retains the individual band states.

This replaces the earlier Mid bell and Mid-Q cut design. Version-1 data retains its Mid frequency/Q fields for compatibility; UI and processing ignore them. Loading an earlier EQ instance uses the new middle-shelf behavior while retaining gain, power, and outer parameters.

The track stores an ordered `effects` list, with a stable UUID and typed versioned payload per instance, plus `effects_compact`. EQ state version 1 stores unit power, horizontal collapse, and all band parameters/states. Missing track fields default to an empty chain and expanded lane. Track duplication copies settings and gives each effect a new ID. Save/reopen, Save As, rate changes, and view/track changes retain these fields. Shared core edits validate finite parameter bounds and unique non-nil IDs atomically. Unknown effect types and future EQ versions retain their opaque state, pass audio through, and report a warning on open.

`daw-unit-core` owns the saved format and portable stereo `EffectUnit` contract. `daw-equalizer` contains FunDSP state-variable filters behind that contract, with independent channel state and no device or DAW dependencies. The shared engine processes clip/instrument output → serial EQ instances → track gain/pan and audibility → Master gain. Muted/solo-excluded tracks continue processing. Filter history continues through clip gaps and transport loops; seek and Stop reset it. Pause retains state. Compatible prepared renderer updates preserve filter history by track/effect ID. Gain, frequency, Q, band cuts, and unit bypass changes ramp over 5 ms; presentation changes do not restart ramps. Processing, reset, and retarget do not allocate or block.

Playback and export use the same sequential runtime. There is no added buffering latency. EQ ringing within the arranged render range is processed; export retains the existing arranged duration. Automatic effect-tail export, beat-lane effects, graph editing, and standalone adapters remain future work. Random-access `RenderPlan` helpers warm the state from frame zero when effects are present; use a persistent `Renderer` for sequential or real-time processing.

Native audio-device behavior and Windows/Linux appearance require separate checks from automated filter and egui tests.

Master supports this unit through the same Timeline catalog and controls. Its independent saved chain processes the summed track bus before Master gain and output meters; see [Master effects](../architecture/modular-audio-units.md#master-effects-implementation--2026-10-14).

## Modulation — 2026-10-17

3-band EQ is a shared modulation destination through the [portable source and destination contract](../modulation/contract.md). It accepts Retrigger/Legato Envelopes, LFOs, and Macro strips from its own MIDI instrument, including Main. Per note and foreign instrument sources fail core validation. Audio tracks and Master can retain unassigned connections but cannot reference an instrument provider. Disconnect a connected Envelope from track effects before changing it to Per note. Disabled, removed, unavailable, or unassigned sources contribute neutral offsets through the common resolver.

| Destination | Signed Amount range | Application and final bounds |
| --- | --- | --- |
| Low · Gain / Mid · Gain / High · Gain | −24 to +24 dB per connection | Add to the band's gain; clamp to −24 to +24 dB. |
| Low · Frequency / High · Frequency | −6 to +6 octaves per connection | Multiply by `2^offset`; clamp to 20 Hz–20 kHz. Both boundaries also control Mid. |
| Low · Q / High · Q | −10 to +10 Q per connection | Add to Q; clamp to 0.1–10. Both Q values also control Mid edges. |

Band and unit power remain discrete controls. Mid has no independent Frequency or Q target; its legacy saved fields remain ignored. Modulation leaves base values, power, and cuts unchanged. Disabled bands retain their gain settings; Frequency and Q continue controlling their cuts. Whole-unit off passes dry audio while filters and modulation continue advancing. Zero offsets preserve the unmodulated audio.

The header's secondary-color dot opens the shared Source/Destination/Amount strips on the right. Connections reuse the common Plus strip, Power/Mod N footer, context-menu removal, and strip reordering. Regular EQ knobs and all three output-level rails stay visible. Compact lanes retain unit and connection footers while hiding knobs and level rails; horizontal collapse hides the body. Visibility edits use the existing effect transaction and mark the project modified. Header power, unit selection, collapse, and drag gestures retain their shared guards.

Every EQ knob and Amount knob derives from `parameter_knobs.rs`. Gain keeps its centered ±24 dB scale, 6 dB marks, and 0.1 dB keyboard steps. Frequency retains its logarithmic scale and 1/24-octave keyboard operation; Q retains its logarithmic scale and shared signed amount adapter. Double-click Amount resets it to zero; Shift retains fine adjustment. Assigned parameters reuse the status dot, correlated-source range arc, source/amount tooltip, click-to-open action, and actual processed-value marker. Base pointers and readouts remain unchanged. A cut band's Gain target still reports its retained processed setting; its gain does not replace the cut path.

Sources publish once per sample and fan out through cached values. `process_modulation` resolves typed signed routes, sums each target before bounds, and excludes per-note input. EQ reuses `ModulationSmoother` for 1 ms offset smoothing, alongside the existing 5 ms base, route amount/power, source-enable, and bypass ramps. Its normal shelf, Mid shelf/cut, and monitor filters all follow the resulting effective boundaries. Live markers use prepared atomic block snapshots with seven readings in Low Gain/Frequency/Q, Mid Gain, High Gain/Frequency/Q order. The existing five-reading host accessors remain compatibility adapters. Processing, route retargeting, snapshots, and reset allocate and lock nothing in the callback.

EQ remains state version 1. Optional `modulation_open` and `modulations` fields default to closed/empty for older projects. Save/reopen, Save As, effect reorder, track duplication, processing-rate changes, and provider moves retain routes and source identity. Effect drag copies create fresh route IDs through the common effect-copy handler. Invalid route IDs, amounts, targets, or source references reject the complete edit. Compatible replacements retain route smoothing by stable ID plus EQ/filter/monitor history; presentation edits do not restart ramps. Stop/seek reset processing; Pause and loops retain the existing transport behavior. Modulation adds no audio latency, sidechain, cross-track routing, or note-release ownership.
