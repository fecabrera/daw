# Chorus

For controls and tasks, see [Chorus](../../docs/effects/chorus.md). This implements the accepted three-strip design: Chorus (Delay/Depth/Feedback), Motion (Hz/Note mode, Rate, Stereo phase, Voices), Out (Width/Level/Dry/Wet).

## Model and shared integration

`unit-core::ChorusSettings` stores version 1 under `daw.chorus`, saved power/collapse/connection visibility, routes and ten controls. Bounds/defaults are in the guide. Rate mode and Note duration reuse `LfoRateMode` and `NoteRate`. Missing fields load as Hz/quarter note, preserving prior Hz settings. Both saved rates persist across mode changes. Voices is a validated whole count, 1–4, and is not a modulation destination. Unknown future state remains a Missing effect with its payload retained. Copy/reorder/transfer/save/open/rate changes use the existing effect transactions and IDs.

Register Chorus once under Imaging in `effects_catalog::ENTRIES`, appended to preserve existing entry indices. Reuse the unit shell, `panels::unit_strip_with_width` with standard panel padding and full-height dividers, standard full-size knob rows (Motion uses the shared two-column layout, with one equal inner/outer gap, mode/rate in the left column, phase/voices in the right column, and a shared centered footer), footer labels, compact/collapse handling, modulation header toggle/body/markers, selection and drag helpers. Out's top rail uses the shared monitor geometry, colors, tooltips and bypass masking. Follow the [two-column spacing standard](../architecture/modular-audio-units.md#two-column-unit-strip-spacing--2026-10-25). No custom knob interaction or shape artwork is introduced.

Six new stable destination slots append at 82–87: Delay (±25 ms), Depth (±1), Feedback (±1.6), Rate (±6 octaves), Stereo phase (±180°), Width (±2). Level/DryWet reuse existing identities and ±24 dB/±1 offsets. `ChorusSettings` and `Chorus` implement the shared destination contract with Shared scope; host route preparation, cached provider lookup, validation/resolution, source filtering and additive offset smoothing remain shared. Extend shared amount definitions and processed-value telemetry; signed amounts always reset to zero, including a native phase control whose reset is 90°.

## Portable processing

`crates/chorus` owns a preallocated stereo f64 ring, eight continuous base controls plus bypass ramps, an optional rate-compensation ramp initialized at the first host rate, four voice weights/phase-offset ramps, the shared `LfoClock` plus an integrated rate-modulation offset, `ModulationSmoother<8>` and `LevelMonitor<3>` (first lane is output, other lanes zero). It has no project, UI, media, device or native dependencies. The sine function reuses `daw-lfo::waveform`; the delay and mixing code is original project code.

Allocate `ceil(0.046 × sample_rate) + 4` stereo frames off the callback, enough for the maximum 43.5 ms read delay and interpolation. Delay for voice i/channel c is `Time × (1 + 0.45 × Depth × Compensation × sin(phase + i/Voices + right_phase))`. Compensation targets `min(1, 0.8 / effective_rate_hz)`, using the final tempo-aware, modulated and bounded rate. Inverse-rate excursion keeps the steady sine-delay velocity, and hence detuning, constant above the default 0.8 Hz reference. Slower rates retain the original excursion so delays stay positive and within the same ring bounds. Initialize compensation directly at the first host rate; subsequent changes use the shared 5 ms ramp to avoid delay jumps. Retarget/clone preserve this ramp; reset clears its initialization. Parameter transitions can still produce temporary pitch movement. Convert ms to project-rate frames. Right phase is zero for L and the saved/processed stereo phase in cycles for R. Use the host frame and shared clock for base phase, including bypass and silence. Hz keeps its saved 0.05–10 Hz range. Note derives frequency and modulation bounds from project tempo and the shared dotted-4-bars/triplet-1/64 endpoints. Integrate rate offsets separately so modulation sweeps retain phase continuity. Base-rate, note-duration and tempo changes use the shared clock’s 5 ms correction; discontinuous positions reset its correction. Voice changes ramp weights and offsets over 5 ms; normalize the weighted sum by active voice weights, with a minimum divisor of one.

Use convex linear fractional interpolation. Read before writing each stereo input plus Feedback times the raw wet signal into the ring. Feedback stays within ±0.8; channel histories are independent. Width scales the wet Side component, retaining wet Mid. Linearly blend dry/wet, then apply Level. Bypass blends that complete result with the unchanged dry input. It reports zero alignment latency: wet delay is intrinsic, and the dry path stays immediate. Nonfinite input is silent; use f64 sums and finite f32 output/storage bounds.

Base settings, power and voice changes ramp over 5 ms; shared modulation offsets smooth over 1 ms. Rate offsets multiply by `2^offset`, gain offsets multiply amplitude, and other offsets add in native units. Final bounds live in the processor. Exact base Level silence remains silent under modulation. Retargeting preserves ring, write cursor, LFO phase and smoothing; clone detaches meter handles. The callback does not allocate, block, perform I/O, or retire owners.

Use the existing band-meter binding/retirement path and `UnitMeter` lifecycle through `LevelMonitor`. Disable clears readings immediately and stops monitor updates; UI masks stale queued values with `meters::unit_reading`. DSP history continues behind bypass.

## Transport and acceptance

Chorus requests the existing full processing-history preparation path so native seek/cache reconstruction includes feedback and clock history on workers. Reuse track, layer, Main, Master, grouped-bus, serial-effect, playback and export processing. Gaps feed silence into the continuing processor. Stop/reset clears buffers and phase; pause retains state through the existing transport fade. Export retains the current arranged-duration policy; automatic tail extension remains outside this change.

Acceptance covers rendered wet-tone frequency deviation across fast Hz rates, note durations, tempo and octave modulation at six project rates, compensation startup/retarget/reset, six-rate delay/feedback/stereo/width behavior, finite boundaries and modulation bounds, meter bypass/clone lifecycle, compatible history and allocation checks, playback/export/prepared-seek parity, all shared modulation targets and owners, persistence/copy/rate changes, and shared UI/catalog interactions. Record executed checks and native/listening/platform limits in [validation](../validation/README.md).
