# Beat editor roadmap

Beat tracks and the beat pattern editor are planned. They are not available in the current application. Use [MIDI patterns](editor.md) or arrange audio clips in Timeline to build rhythms today.

## Planned workflow

The planned beat editor uses rows of steps. Each lane will play audio or MIDI, with a common pattern length and step resolution. Lane controls will choose sound sources, effects, and timing. Beat patterns will appear as clips in Timeline, and Mixer will control the whole beat track.

Planned capabilities include lane stop connections and independent lane processing. These are design goals, not current controls. See the [features and roadmap](../roadmap.md) for the wider project scope.
