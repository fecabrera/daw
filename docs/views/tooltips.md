# Tooltips and Details

Hover a control to see a short label or its current value. The app and standalone
plugin editors use the same formats.

| Surface | What the tooltip shows |
| --- | --- |
| Parameter | Its name and current value, or just the value |
| Action button | The action name and its shortcut, when available |
| Meter | Current and held levels, with units |
| Name or source | The full name or source path |
| Status | A short status or reason |
| Graph handle | Its current values |

Knob tooltips stay visible during a drag and follow the value. Release ends the
drag tooltip. Use the relevant control guide for gestures, limits and defaults.

Choose **Details** beside the processing-rate and buffer status to view memory
estimates, budgets and accounting notes. When transient analysis fails, choose
**Details** beside its status to read the complete error.

Reports do not change the project or stop playback. Editing is disabled while
a report is open. Choose **Close** or press Escape to dismiss it.
