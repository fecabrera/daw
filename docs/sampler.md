# Sampler source

Implemented design, 2026-10-17. Sampler is an instrument component for regular MIDI layers. It plays a selected mono/stereo audio region for each MIDI note, at the sample's original pitch. Pitch transposition is deferred until the time-stretch library supports it. See the [acceptance requirements](../specs/mvp-iteration-1.md#sampler-source--2026-10-17) and [validation record](validation.md).

## Placement and source ownership

Register Sampler once in the Instrument components catalog. A layer can have one Oscillator component or one Sampler component; the Oscillator component can still contain multiple oscillator strips. Empty layers remain silent. Sampler stays first in the layer and cannot enter Main. Conflicting catalog additions and installed transfers leave the project unchanged and show an unsupported-target hint. A catalog selection containing both source types cannot enter a regular layer.

Source headers offer an explicit **Replace source** action. Replacement keeps the layer's identity, mix settings, modulators, and Amplitude stage. It discards the old source settings and oscillator pitch routes when applicable. Component selection, Delete/Backspace, header group moves/copies, focus, insertion previews, and cancellation reuse the existing component paths. Sampler copies receive a fresh sampler ID and share the immutable audio asset. Removing Sampler discards its settings; retained Envelope/LFO/Macro/Amplitude settings keep their existing restoration rules.

## Loading and selecting audio

1. Add Sampler to an empty regular layer, or replace its Oscillator component through the header menu.
2. Drop one supported WAV file onto the unit. File decoding, project-rate conversion, and waveform preparation use the existing media/worker path. Mono/stereo PCM16, PCM24, and float32 WAV support matches ordinary import.
3. To use a timeline audio clip, drag it over the Instrument view button. This opens Instrument on the first MIDI track with a Sampler. Drop onto that unit. The original timeline clip stays in place. The sampler retains its source trim, repeat length/phase, and existing stretch mapping; track gain, pan, and effects are not captured.
4. Drag the preview's selection-bar edges to resize the region, its body to move it, or outside the current region to create another region. Shift bypasses the shared musical-grid/source-boundary snapping. Preview during the gesture; commit only on release. Escape, focus loss, or disabled editing cancels it.

The source initially spans the full file or visible dropped clip. Selection uses integer frames on that input's local clock and never changes the recording or project loop selection. The filename is inside the clip header, using the common clip-header painter. Mono/stereo peaks reuse the Timeline waveform painter. The preview shows the standard bar/beat ruler and grid, including zoom-dependent subdivisions, through the same painters as Timeline and Editor. Its clock starts at local frame zero and uses the effective playback duration at project tempo/rate. Off uses the original input clock. Time/Bars scale the full preview by the selected region's prepared output/input ratio: a one-bar target spans one bar across that region, including when the region is only part of the file. The grid adapts to duration, tempo, mode, and committed selection changes; arrangement scroll/zoom stays independent. Grid lines span both waveform channels. Selection snapping maps through the same ratio back to input frames, with Shift retaining free movement. The selection bar shares the project loop ruler's painting, colors, handles, and hit geometry; it selects playback content without enabling repetition. A read-only marker shows an actual active voice position through prepared atomic telemetry. With overlapping notes, it shows the furthest active position. No UI clock advances playback.

Dropping a replacement resets selection to the new full input. An explicitly set Time/Bars target remains unchanged. Loading, region changes, and duration changes publish the new project and prepared audio together. Failure or Cancel retains the previous settings, sample, and playback. Missing external files retain the saved input and display a missing-source state, with silent rendering. Shortened files supply silence for unavailable ranges. Save and Save As preserve external references; they do not bundle recordings.

## Controls

| Control | Behavior and defaults |
| --- | --- |
| Gain | Existing marked gain knob, exact silence through +12 dB; default 0 dB. Reuse pointer/keyboard handling, Shift sensitivity, unity mark, and double-click reset. Gain and unit power ramp over 5 ms. |
| Stretch mode | Standard dropdown in the duration group: **Off / Time (ms) / Bars**, default Off. The closed selector shows Off, ms, or bars. It stays visible in expanded units, including Off. There is no separate stretch-mode knob. |
| Duration | Always shown in expanded units. Off displays the original selected duration in milliseconds as a disabled numeric readout (0 before loading). Time/Bars use the standard drag/numeric input, milliseconds or whole four-beat bars. Bars has a minimum of 1 and stable 1-bar drag steps, including with Shift. Switching to Bars rounds the current output duration to the nearest whole bar, with a minimum of 1. Switching to Time preserves the current output duration. Selection changes retain an explicit target. |
| Trigger | Standard **One-shot / Gate** dropdown beside root note and duration, default One-shot. Reuse the duration selector helper, small text, tooltip, and accessibility metadata. |
| Root note | Note-name input and adjacent sharp toggle; default C4 (MIDI 60). Use the same C−1–G9 naming/range as the piano roll. Drag the box through MIDI notes in semitone steps (10 points per step; Shift slows adjustment tenfold). The sharp toggle follows accidental crossings. Preview while dragging and commit on release; Escape, focus loss, or disabled editing cancels the drag. Click the box to type. The box accepts natural names such as A3/B2/C4, with the octave in the same input. The separate sharp toggle supplies the accidental. Disable sharp for E, B, and out-of-range combinations such as G9. Enter or focus loss commits valid text; Escape or invalid text retains the previous note. Root note is saved metadata and has no pitch effect yet. |

Off preserves the selected input duration. Time stretches to a fixed number of milliseconds, independent of tempo. Bars stretches to a musical duration that follows project tempo. Both preserve pitch through the saved project stretch backend/revision. Round the output length to the nearest project sample frame. Require a positive output length and a duration ratio within 1/8–8 of the selected region; reject the complete edit otherwise. Time accepts positive finite milliseconds; Bars stores positive whole bars; project validation applies these frame/ratio bounds. Before loading audio, Time defaults to 1000 ms and Bars to 1 bar. First load initializes Time from the original input duration and Bars from its nearest whole-bar duration, with a minimum of 1. Saved fractional-bar prototype values round to the nearest whole bar on load, with a minimum of 1; output frame/ratio validation still applies.

One-shot keeps the source running to the selected region's end after MIDI note-off. Gate follows the existing note gate and Amplitude release behavior. Trigger changes apply to new notes; existing notes keep their trigger behavior. Neither mode repeats the selected region. Existing Amplitude modulation can shape or silence either source, and MIDI velocity scales each voice. Both modes stop at the source end and follow existing clip/loop/transport boundaries. All MIDI pitches trigger the same original pitch. Stereo channels retain their relationship through the same Amplitude factor, layer mix, Main, and track effects. Boundary fades are 5 ms.

Root note and the sharp toggle form one joined input group, with a shared outline and internal divider. Match its full outer height, including the border, to the standard 22-point duration input in display and text-entry states. Use the shared 11-point numeric font for the root note, sharp toggle, duration value, and dropdowns. Duration is a second joined input group: a centered drag/text value and a separate Off/ms/bars mode dropdown, with one outline and internal divider. Keep its full width fixed at 120 points, including a 60-point mode segment, in display and text-entry states. Scale only an unusually long duration value below 11 points when needed to fit the numeric segment. The dropdown remains visible while editing and owns stretch-mode changes. With no pending value edit, opening it, cancelling it, or selecting the current mode leaves the project clean. Stretch-mode changes use the existing instrument edit and worker preparation; errors retain the current settings/audio. Trigger changes use the same instrument edit without rebuilding prepared audio. Opening, cancelling, or selecting the current Trigger choice leaves the project clean. Both retain their separate drag/text and toggle interactions. The root-note group, duration group, and 76-point Trigger dropdown share one horizontal row below the preview, with 4-point gaps. All controls have the same 22-point outer height. Omit visible Root note and Duration labels; retain tooltips, accessible names, and duration mode names. Gain occupies the first row of one standard 90-point strip, including the shared padding. Center the Sample label in the bottom footer row, aligned with the other unit footers. Reserve the two remaining control rows to keep the standard footer position. A shared full-height divider separates this strip from the waveform section. The shared unit shell owns power, collapse, selection, and header behavior. Compact layers retain the source name/footer and hide waveform/controls; horizontal collapse hides the body. Both retain a sample drop target. Expanded layers retain their existing height. Parameters remain editable while the unit is off; muted sources keep advancing.

## Architecture and saved state

`unit-core` owns version-1 `SamplerSettings`, `SamplerInput`, trigger/mode enums, shared clip repeat/stretch value types, MIDI note naming, and the portable `StereoSourceUnit` contract. Optional layer `sampler` defaults to absent and retains instrument version 3. Old oscillator-only instruments retain their source lists and sound. Core validates source exclusivity, supported audio assets, positive bounded ranges, durations, note range, finite gain, unique sampler IDs, and transfers atomically. Project-rate changes rescale selection/input/repeat frame coordinates with the existing checked arithmetic; Time and Bars retain their units.

`crates/sampler` owns allocation-free stereo playback, local position, gain/power ramps, and boundary fades. It has no project, UI, media, or device dependency. The host supplies an immutable prepared stereo buffer and note triggers. `crates/project` composes the retained clip mapping and selected region, then prepares its constant-ratio output through the existing stretch cache/backend. Prepared output uses the unique sampler ID in the render plan's audio map; original assets keep their own IDs and buffers. Only workers prepare or replace those buffers.

The shared MIDI runtime owns voice allocation, note timing, seek reconstruction, looping, velocity, and Amplitude modulation. It advances Amplitude once per layer/voice and applies the resolved gain to both stereo channels. Existing oscillator arithmetic remains unchanged. Compatible Gain/power/root/presentation edits retain sample positions and in-flight ramps without callback allocations or final-owner retirement. Content/duration replacements use the existing prepared-renderer transition and note-age reconstruction. Pause retains positions; Stop/seek use existing transport resets. Live playback and offline export share this path.

Sampler currently publishes no modulation source and adds no modulation destinations. Future pitch or other modulation must use the [shared source/destination contract](modulation.md). Reverse playback, internal looping, slicing, automatic pitch/tempo detection, multisampling, and pitch shifting remain outside this version.
